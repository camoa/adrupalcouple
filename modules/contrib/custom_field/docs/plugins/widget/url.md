# Url widget
The **Url** (`url`) widget provides a user-friendly interface for entering web
addresses using the native HTML `<input type="url">` element.

## Settings
| Setting       | Label                   | Description                                             | Default |
|---------------|-------------------------|---------------------------------------------------------|:--------|
| placeholder   | Placeholder             | Text shown inside the field when empty                  |         |

## Field types
- [uri](../type/uri.md)
