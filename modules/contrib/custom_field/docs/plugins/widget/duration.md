# Duration widget
The **Duration** (`duration`) widget provides a custom select form element
containing an option list of durations keyed by the duration in seconds. The
options are derived from the `duration_options` field setting.

## Settings
| Setting          | Label            | Description                                                          | Default |
|------------------|------------------|----------------------------------------------------------------------|:--------|
| duration_element | Duration element | They type of form element (Pre-defined options list or input fields) | options |

## Field types
- [duration](../type/duration.md)
- [daterange](../type/daterange.md)
