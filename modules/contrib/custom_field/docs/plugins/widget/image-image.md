# Image widget
The **Image** (`image_image`) widget provides the `<input type="image">` 
form element which defines an image as a `submit` button.

## Settings
| Setting             | Label               | Description                                    | Default   |
|---------------------|---------------------|------------------------------------------------|:----------|
| progress_indicator  | Progress indicator  | Indicator to show file is uploading            | throbber  |
| preview_image_style | Preview image style | Style of the preview image shown while editing | thumbnail |
